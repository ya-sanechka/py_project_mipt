Идея проекта:
Веб-приложение, куда пользователь заходит и логинится через свой телеграмм аккаунт. Там можно выбрать чат, который пользователь хочет проанализировать. Мы строим связи между людьми в чате на основании их взаимодействия в переписке - смотрим кто кого тегает, кому отвечает, кому ставит реакции. По результатам строим граф, где можно по толщине ребра понимать степень взаимодействия, интерактивно тыкать на вершинки и тд. Так же найдем в этом графе точки сочленения, мосты (то есть связи, на которых держится общение), компоненты сильной связности (подгруппы) и другое. Можно так же насобирать интересные статистики - в какое время активнее всего пишут, топ юзеров по активности, процентные соотношения сообщений, мб можно найти фирменные фразы/словечки участников группы или что-то такое. В общем можно много прикольных фич добавить, пользуясь данными
